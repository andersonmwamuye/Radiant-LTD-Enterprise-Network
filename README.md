# Radiant-LTD-Enterprise-Network
Comprehensive 4-story enterprise network design for Radiant Co. Ltd (Nairobi). Implements secure SSH management, VLAN segmentation, port security across 12 switches, VLSM subnetting, OSPF routing, Inter-VLAN routing via Layer 3 switches, DHCP relay, enterprise wireless, and end-to-end connectivity testing.
